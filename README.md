# Simple Todo App (React + TypeScript + Vite)

A minimal CRUD todo app.

## Features
- **Create**: add a new todo via the input form
- **Read**: view all todos in a list
- **Update**: check/uncheck to mark complete, or click "Edit" to change the text
- **Delete**: remove a todo

## Setup

```bash
npm install
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Project structure

```
todo-app/
├── index.html          # HTML entry point
├── package.json        # dependencies & scripts
├── tsconfig.json       # TypeScript config
├── vite.config.ts      # Vite config
└── src/
    ├── main.tsx         # mounts <App /> into the page
    ├── App.tsx          # all CRUD logic + UI lives here
    └── App.css          # styling
```

All the todo logic (add, toggle, edit, delete) is in `src/App.tsx`,
with comments explaining each step.
